# 🌐 Digital Profile - Rafif Ersan Dzaky

Website profil interaktif (*Link in Bio / Linktree alternative*) yang modern, elegan, dan ultra-ringan, dirancang untuk personal branding digital menuju visi 2045.

🔗 **Live Website:** [https://erzandz11-glitch.github.io/Profil-digital/](https://erzandz11-glitch.github.io/Profil-digital/)

---

## 🚀 Fitur Utama
- **Ultra-Lightweight & Fast:** 100% Client-side tanpa build tool berat, loading instan.
- **Modern Dark UI:** Tampilan elegan berbasis Tailwind CSS dengan aksen glow neon.
- **Direct Connect:**
  - WhatsApp Direct Chat (Format internasional terstandarisasi)
  - Instagram Profile Link
  - GitHub Developer Portfolio
- **Fully Responsive:** Tampilan rapi dan presisi di HP, Tablet, maupun Desktop.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** - Struktur semantik halaman
- **Tailwind CSS (CDN)** - Styling modern & utility-first tanpa kompilasi lokal
- **Font Awesome 6** - Ikon sosial media beresolusi tinggi
- **UI Avatars API** - Generator inisial profil otomatis
- **GitHub Pages** - Hosting cloud 100% gratis & permanen
